# Base de datod de un Gimnasio

## Objetivo : 

Crear una base de datos en MongoDB para administrar la información de un gimnasio, permitiendo almacenar datos de usuarios, membresías, trabajadores, entrenadores y productos.

________________________________________

### Colecciones a crear

#### Usuarios
Almacenará información de los clientes registrados en el gimnasio.

#### Membresías
Guardará los diferentes planes disponibles, precios y beneficios.

#### Trabajadores
Contendrá los datos de los empleados del gimnasio.

#### Entrenadores
Permitirá registrar entrenadores, especialidades y experiencia.

#### Productos
Almacenará productos vendidos dentro del gimnasio como suplementos o bebidas.
